# Kenney particle atlas

`particle_atlas.png` packs eight transparent sprites from the Kenney Particle Pack: smoke_04,
smoke_07, dirt_01, dirt_03, spark_01, spark_02, scorch_01 and flame_05. Kenney publishes the pack
under CC0 1.0: https://kenney.nl/assets/particle-pack

The 4 × 2 atlas is sampled by `scripts/particles.gd` through per-instance frame indices. The source
PNG collection remains in the local `incoming-assets/` inbox and is not part of the project.
